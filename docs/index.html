Run it yourself

python3 -m csvlens examples/messy.csv  ·  python3 -m csvlens data.csv --format html  ·  python3 -m csvlens data.csv --fail-on messy for a CI gate (exit 1 on MESSY, 2 on unreadable files).

Zero shipped dependencies — Python standard library only. Scoring: error −10, warning −5, info −2; grades A 90+, B 75+, C 60+, D 40+, F below 40; verdicts CLEAN / NEEDS WORK / MESSY.
